# qwdtt-cli

Консольный клиент к протоколу qWDTT: VPN поверх TURN-инфраструктуры звонков VK.
Трафик уходит на ваш VPS через TURN-relay ВКонтакте и для сети выглядит как медиапоток
звонка WebRTC, а не как подключение к VPN-серверу.

> **Проект в разработке.** Рабочей сборки пока нет. Текущее состояние — в
> [`doc/plan-e1.md`](doc/plan-e1.md).

## Что это и чем не является

Это только клиент. Установка и настройка серверной части, панель управления, импорт
подписок и сканирование QR остаются в Android-приложении
[qWDTT](https://github.com/SpaceNeuroX/proxy-turn-vk-android) — здесь их нет и не будет.

Клиент работает на переднем плане: пока запущен `tt connect`, туннель поднят.
Службы Windows и автозапуска нет.

## Планируемые возможности

- Подключение по профилю из конфигурационного файла, секреты под DPAPI
- Три способа доставки трафика: SOCKS5 без прав администратора, свой адаптер Wintun,
  передача конфигурации штатному WireGuard
- Проверка хешей VK и замер задержки до сервера
- Автоматическое восстановление при обрыве и смене сети

## Сборка

```
go build ./cmd/tt
```

Требуется Go 1.26 или новее.

## Предупреждения

Релизные бинари пока не подписаны. Windows SmartScreen и антивирусы могут возражать
против программы, которая создаёт сетевой адаптер, — это ожидаемо до появления подписи.
